## Homepage capture setup

The rune exchange, reach comparison and fractured exit were recorded from the v0.57 Unity campaign simulation using an isolated save. The setup collects eight runes, grants the required abilities and positions the player for repeatable examples. These are prepared demonstrations, not a continuous first-time playthrough.

The exchange calls the repository's normal select/remove/equip handlers and altar rule. Shockwave, collision, terrain destruction, animation and UI run through existing gameplay code. No rune or combat parameters were changed. Nearby enemies were held inactive for these focused examples. No training-room controls, desktop overlays or cursor are included.

The map figure uses the existing Unity scene overview with explanatory labels; it is not the in-game map interface. The title image is an illustration. Only curated publication images and GIFs are added; raw recordings, model runtimes, account/session material and private saves stay local.
